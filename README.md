# KeyTrainer Analytics — клавиатурный тренажер с аналитикой

Десктопное приложение для обучения слепой печати. Программа сама составляет упражнения
в пяти режимах, считает WPM, CPM и процент ошибок, показывает слабые клавиши
на тепловой карте и ведет историю тренировок по профилям. Работает без интернета.

## Возможности
- 5 режимов: изучение клавиш (по рядам), случайные слова, связный текст,
  работа над ошибками (адаптивный), свой текст (ввод или TXT-файл);
- длина 10–200 слов или 30/60/120 секунд; заглавные, цифры, знаки — по выбору;
- метрики в реальном времени, экранная клавиатура с подсказкой пальца;
- карточка результатов: сравнение с рекордом и средним за 10 сессий;
- тепловая карта (процент ошибок / время реакции, 4 периода, RU/EN), топ-5 проблемных клавиш;
- история с графиком, сортировкой, удалением и экспортом в CSV для Excel;
- профили (создание, переименование, переключение, удаление) с личными настройками;
- светлая и темная темы, размер шрифта 14–32, автопауза при потере фокуса;
- плавные анимации по спецификации макета Figma (см. ниже).

## Анимации
Все длительности взяты со страницы Figma «СПЕЦИФИКАЦИЯ». Анимации сделаны средствами
Tkinter (`after()` ≈ 60 кадров/с) без сторонних библиотек — модуль `views/animation.py`.

| Элемент | Поведение |
|---|---|
| клавиша | наведение — фон +6 %, нажатие — вспышка и scale 0,96 за 0,1 с, ошибка — приглушенный красный |
| каретка | скользит между буквами 0,09 с, мигает в простое, при ошибке красная 0,26 с |
| текст | при ошибке встряхивается 0,22 с; новый текст проявляется, на паузе приглушается |
| боковое меню | выезжает за 0,38 с: Esc, клик или наведение на левый край окна |
| экраны и списки | экран мягко поднимается, выпадающие списки раскрываются |
| результаты | цифры «набегают» от нуля, блоки появляются по очереди |
| тепловая карта | цвета разливаются волной и перетекают при смене фильтра |
| история | график рисуется слева направо, строки таблицы проявляются |
| тема | плавный переход светлая ↔ темная |

## Технологии
Python 3.10+, Tkinter, SQLite (`sqlite3`), matplotlib, pytest, Poetry,
black + flake8 (pre-commit), PyInstaller.

## Архитектура
Многослойная архитектура, паттерны MVC, Repository, Observer:

```
keytrainer/
  app.py             сборка приложения
  config.py          пути (pathlib), логирование
  labels.py          русские подписи интерфейса
  data/              Data Access: схема, транзакции, резервная копия, репозитории
  engine/            Model: генератор, сессия набора, метрики, аналитика, история, CSV
  controllers/       Controller: обработка клавиш, фоновые расчеты, профили
  views/             View: окно, экраны, виджеты, диалоги, анимации (Tkinter)
  utils/             фоновые потоки, чтение TXT
  resources/         словари (≥ 1000 слов на язык) и тексты
tests/               pytest
docs/                Daily Scrum, code review, инструкция по релизу
keytrainer.spec      сборка KeyTrainer.exe (PyInstaller)
```
Слой `engine` не импортирует tkinter и проверяется тестами без интерфейса.

## Установка и запуск

Windows, без Poetry:
```powershell
py -m pip install -r requirements.txt
py -m keytrainer
```

С Poetry:
```bash
poetry install
poetry run pre-commit install
poetry run python -m keytrainer
```
В Linux для Tkinter нужен пакет `python3-tk`. Для внешнего вида как в макете
установите шрифт JetBrains Mono (иначе используется Consolas / DejaVu Sans Mono).

Тестовые данные (чтобы сразу увидеть статистику и историю):
```bash
py -m keytrainer.data.demo_data --user Гость --sessions 30
```

## Горячие клавиши
Tab — заново, Enter — завершить, Ctrl+P — пауза, Esc — меню, F1 — справка.

## Проверка качества
```bash
py -m pip install -r requirements-dev.txt
py -m black --check .
py -m flake8
py -m pytest
```

## Сборка .exe
```powershell
py -m PyInstaller keytrainer.spec
```
Готовый файл — `dist\KeyTrainer.exe`. База данных, журнал и настройки создаются рядом с ним
(portable-режим). Порядок выпуска версии — в [docs/release.md](docs/release.md).
