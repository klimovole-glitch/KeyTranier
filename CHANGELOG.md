# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0]
### Добавлено
- База данных SQLite из 7 таблиц (3NF), транзакции, резервная копия и восстановление,
  CRUD-репозитории с параметризованными запросами (день 7, PR #2).
- Ядро: генератор упражнений в 5 режимах, учет нажатий, метрики WPM / CPM / % ошибок,
  сохранение сессий (день 8, PR #3).
- Главное окно, экран тренировки, экранная клавиатура с подсказкой пальца,
  карточка результатов, пауза и автопауза (день 9, PR #4).
- Тепловая карта клавиатуры, топ-5 проблемных клавиш, режим «работа над ошибками»,
  расчеты в фоновом потоке (день 10, PR #5).
- История тренировок с графиком, сортировкой, удалением и экспортом в CSV (день 11, PR #6).
- Профили и настройки: тема, размер шрифта, раскладка и режим по умолчанию (день 11, PR #7).
- Анимации по спецификации Figma: клавиатура, каретка, встряска при ошибке, выезжающее меню,
  выпадающие списки, переходы экранов, «набегающие» цифры, волна тепловой карты,
  рисующийся график, плавная смена темы (день 12, PR #8).
- README, Daily Scrum, шаблон code review, сборка `KeyTrainer.exe` (день 12).
