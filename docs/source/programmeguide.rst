Руководство программиста
========================

1. Назначение и условия применения
----------------------------------
Данное руководство предназначено для разработчиков, поддерживающих и развивающих программный продукт «KeyTrainer Analytics».

**Условия применения:**
* Наличие установленного интерпретатора Python версии 3.10 или выше.
* Наличие системы контроля версий Git.
* Менеджер пакетов Poetry (рекомендуется) или пакетный менеджер pip.

2. Характеристика программы
---------------------------
Программа реализована на языке Python. Графический интерфейс построен на базе библиотеки Tkinter. Взаимодействие с данными осуществляется через встроенную реляционную СУБД SQLite.

**Архитектурные паттерны:**
* **MVC (Model-View-Controller):** Разделение логики данных, пользовательского интерфейса и управления.
* **Repository:** Инкапсуляция логики работы с базой данных в отдельные классы-репозитории.

**Основные модули:**
* ``engine`` — ядро приложения (генератор упражнений, расчет метрик WPM/CPM, аналитика). Не зависит от GUI.
* ``views`` — экраны и виджеты Tkinter, анимации.
* ``controllers`` — обработка событий клавиатуры, связующее звено.
* ``data`` — репозитории для работы с SQLite, миграции.

3. Обращение к программе
------------------------
Для запуска приложения из исходного кода выполните следующие шаги:

**Шаг 1. Клонирование репозитория:**
.. code-block:: bash

   git clone https://github.com/klimovole-glitch/KeyTranier.git
   cd KeyTranier

**Шаг 2. Установка зависимостей и запуск:**
.. code-block:: bash

   poetry install
   poetry run python -m keytrainer

4. Входные и выходные данные
----------------------------
**Входные данные:**
* События клавиатуры (нажатия клавиш) от пользователя.
* Параметры упражнения: режим, длина текста, раскладка, включение цифр/знаков.
* Текстовые файлы (TXT) для режима «Свой текст».

**Выходные данные:**
* Записи в базе данных ``keytrainer.db`` (таблицы ``tbl_sessions``, ``tbl_key_stats``).
* Файлы экспорта статистики в формате ``.csv``.
* Графики и визуализации (тепловая карта) на экране.

5. Структура проекта
--------------------
.. code-block:: text

   keytrainer/
     app.py             сборка приложения
     data/              Data Access: схема, транзакции, репозитории
     engine/            Model: генератор, сессия набора, метрики
     controllers/       Controller: обработка клавиш, профили
     views/             View: окно, экраны, виджеты, анимации
     resources/         словари и тексты

6. Проверка и тестирование
--------------------------
Для проверки работоспособности кода используются автоматические тесты (pytest).

.. code-block:: bash

   py -m pytest

.. note::
   Слой ``engine`` не импортирует Tkinter, что позволяет тестировать бизнес-логику без запуска графического интерфейса.

7. Сообщения программисту
-------------------------
При возникновении ошибок в ходе выполнения программы они записываются в файл ``keytrainer.log``, расположенный рядом с исполняемым файлом. Для отладки рекомендуется запускать приложение из терминала для просмотра вывода консоли.
