Руководство системного программиста
===================================

1. Общие сведения о программе
-----------------------------
Программа «KeyTrainer Analytics» представляет собой десктопное приложение для обучения слепой печати. Работает автономно (Portable), не требует подключения к сети Интернет и сторонних серверов.

**Технические и программные средства:**
* **ОС:** Windows 10/11 (64-bit) или Linux (Ubuntu 22.04+).
* **ОЗУ:** Минимум 2 ГБ.
* **Диск:** Около 150 МБ свободного пространства для exe-файла и базы данных.

2. Структура программы
----------------------
Программа состоит из следующих составных частей:
* Исполняемый файл ``KeyTrainer.exe`` (содержит интерпретатор Python, библиотеки и ресурсы).
* База данных ``keytrainer.db`` (создается при первом запуске).
* Файл журнала ``keytrainer.log`` (логи работы и ошибок).
* Резервная копия базы ``keytrainer.db.bak``.

3. Настройка программы
----------------------
3.1. Настройка на состав технических средств
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Программа не требует сложной установки. При переносе на другой компьютер достаточно скопировать файл ``KeyTrainer.exe``. Для сохранения истории тренировок скопируйте также файл ``keytrainer.db``.

3.2. Выбор функций и настроек
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Настройка параметров (тема, шрифт, раскладка) осуществляется через встроенное меню «Настройки» (вызывается клавишей :kbd:`Esc`).

4. Проверка программы
---------------------
4.1. Способы проверки
~~~~~~~~~~~~~~~~~~~~~
Для проверки целостности базы данных и корректности работы программы используются встроенные механизмы и автоматические тесты.

.. code-block:: bash

   py -m pytest

4.2. Контрольные примеры
~~~~~~~~~~~~~~~~~~~~~~~~
* Запуск приложения и прохождение упражнения в режиме «Случайные слова».
* Проверка сохранения сессии: после завершения упражнения данные должны появиться на вкладке «История».
* Проверка экспорта: нажатие кнопки «Экспорт в CSV» должно создавать файл, корректно открывающийся в Microsoft Excel.

5. Дополнительные возможности
-----------------------------
* Экспорт истории в CSV с кодировкой UTF-8 (BOM) для корректного отображения кириллицы в Excel.
* Наличие адаптивного режима «Работа над ошибками», который генерирует текст на основе слабых клавиш пользователя.

6. Сообщения системному программисту
------------------------------------
* **Информационные:** «База данных успешно инициализирована», «Резервная копия создана».
* **Предупреждения:** «Файл keytrainer.db поврежден, восстановление из резервной копии».
* **Ошибки:** «Не найдены ресурсы программы», «Ошибка доступа к файлу базы данных».

.. warning::
   Если программа не запускается, проверьте права на запись в папке, где она находится. Не рекомендуется размещать ``KeyTrainer.exe`` в системных папках (например, ``C:\Program Files``).
