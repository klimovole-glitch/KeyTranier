Руководство пользователя
========================
1. Назначение программы
-----------------------
Программа «Клавиатурный тренажер с аналитикой» (KeyTrainer Analytics) предназначена для обучения быстрой и безошибочной печати.
2. Условия выполнения
---------------------
ОС: Windows 10/11 или Linux. ОЗУ: от 2 ГБ.
3. Выполнение программы
-----------------------
Запустите KeyTrainer.exe двойным кликом. Выберите режим и нажмите «Старт».
