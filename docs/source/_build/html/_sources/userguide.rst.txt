Руководство пользователя
========================

1. Назначение программы
-----------------------

Программа «Клавиатурный тренажер с аналитикой» (KeyTrainer Analytics) предназначена для обучения быстрой и безошибочной печати на локальном персональном компьютере.

Программа включает следующие основные функции:

* Генерация упражнений в 5 режимах (изучение клавиш, случайные слова, связный текст, работа над ошибками, свой текст).
* Отображение метрик в реальном времени (WPM, CPM, процент ошибок).
* Визуализация проблемных клавиш на тепловой карте.

2. Условия выполнения программы
-------------------------------

Для корректной работы программы необходимы следующие технические и программные средства:

* **Операционная система:** Windows 10/11 или Linux (Ubuntu 22.04 и новее).
* **Процессор:** x86-64, от 1.4 ГГц.
* **ОЗУ:** не менее 2 ГБ.
* **Свободное место на диске:** не менее 150 МБ.
* **Разрешение экрана:** не менее 1024x768.

3. Выполнение программы
-----------------------

3.1. Загрузка и запуск программы (Windows)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Скачайте исполняемый файл ``KeyTrainer.exe`` из раздела Releases репозитория.
2. Поместите файл в папку, в которую у вас есть права на запись (например, *Документы\KeyTrainer*).
3. Запустите файл двойным кликом. Первый запуск может занять 2–3 секунды.

3.2. Запуск программы (Linux)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Для операционной системы Linux готовый файл ``.exe`` не подходит. Запуск осуществляется из исходного кода:

1. Установите Python 3.10+ и пакет ``python3-tk``.
2. Установите зависимости: ``pip install -r requirements.txt``.
3. Запустите приложение командой: ``python -m keytrainer``.

3.3. Управление выполнением программы
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* **Выбор режима:** На главном экране тренировки выберите нужный режим из выпадающего списка.
* **Настройка параметров:** Выберите раскладку (ЙЦУКЕН или QWERTY), длину упражнения и дополнительные символы.
* **Запуск:** Нажмите кнопку «Старт» или клавишу :kbd:`Tab`.
* **Пауза:** Нажмите :kbd:`Ctrl+P` или просто переключитесь в другое окно (сработает автопауза).
* **Завершение:** Нажмите :kbd:`Enter` для досрочного завершения или дождитесь конца текста.

.. warning::
   Не удаляйте файл ``keytrainer.db`` из папки с программой, иначе вы потеряете всю историю тренировок и настройки профилей!

4. Сообщения оператору
----------------------

В ходе выполнения программы пользователю могут выдаваться следующие сообщения:

* **Информационные:** «Упражнение завершено», «Данные сохранены».
* **Предупреждения:** «Переключите раскладку», «Время истекло».
* **Ошибки:** При повреждении базы данных программа автоматически создаст резервную копию и восстановит данные.
