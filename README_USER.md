Инструкция по запуску и настройке приложения



1\. Запуск приложения:

Для запуска программы не требуется установка Python или дополнительных библиотек. В среде разработки (VS Code) нажмите правой кнопкой мыши на файл KeyTrainer.exe в папке dist\\KeyTrainer и выберите «Reveal in File Explorer» (Показать в проводнике). В открывшейся папке дважды кликните по файлу KeyTrainer.exe.



2\. Настройка:

Программа не требует сложной настройки. Все данные (статистика, прогресс) сохраняются автоматически в базе данных keytrainer.db. Для сброса прогресса достаточно удалить файл keytrainer.db.



3\. Устранение возможных проблем (Troubleshooting):

\- Если приложение не запускается, проверьте настройки антивируса и добавьте KeyTrainer.exe в исключения.

\- Если появляется ошибка «Не найдены ресурсы», убедитесь, что папка \_internal лежит рядом с исполняемым файлом.

\- Если программа закрывается сразу после запуска, удалите файл базы данных keytrainer.db (прогресс сбросится, создастся новый файл).
